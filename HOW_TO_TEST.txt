========================================
QUICK START - HOW TO TEST THE API
========================================

1. SETUP
--------
npm install
cp .env.example .env
# Edit .env: Set JWT_SECRET=your_secret_key
npm run dev

Server runs on: http://localhost:3000


2. RUN AUTOMATED TESTS
-----------------------
npm test

Expected: 95 tests pass in ~3 seconds


3. MANUAL TESTING (curl)
-------------------------

A) Check Health:
curl http://localhost:3000/health

B) Register User:
curl -X POST http://localhost:3000/api/v1/auth/register -H "Content-Type: application/json" -d "{\"email\":\"test@example.com\",\"password\":\"Test123!\",\"name\":\"Test User\"}"

C) Login (Save the token from response):
curl -X POST http://localhost:3000/api/v1/auth/login -H "Content-Type: application/json" -d "{\"email\":\"test@example.com\",\"password\":\"Test123!\"}"

D) Get Profile (Replace YOUR_TOKEN):
curl http://localhost:3000/api/v1/auth/me -H "Authorization: Bearer YOUR_TOKEN"

E) Get Products:
curl http://localhost:3000/api/v1/products

7. TROUBLESHOOTING
------------------
Issue: "No authorization token provided"
Fix: Add header: -H "Authorization: Bearer YOUR_TOKEN"

Issue: "Admin access required"
Fix: Add user ID to .env: ADMIN_USER_IDS=your-user-id

Issue: Tests failing
Fix: npm install && npm run build && npm test
